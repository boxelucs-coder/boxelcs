Privacy Policy

Last updated: June 2026

1. Overview

BoxelCS ("the App") is a personal, single-user software tool operated by its developer ("the Operator") to publish original video content to the Operator's own social media accounts.

2. Data We Collect

The App does not collect, store, or process any personal data from the public or from any third parties. The only account data the App handles belongs to the Operator: authentication tokens issued by TikTok or YouTube that allow the App to post to the Operator's own accounts.

3. How Data Is Stored

Authentication tokens are stored locally on the Operator's personal computer. No data is transmitted to any server other than the official APIs of TikTok and YouTube for the purpose of publishing content.

4. Data Sharing

The App does not sell, share, or disclose any data to third parties.

5. YouTube API Services

The App uses YouTube API Services to upload the Operator's videos to the Operator's own YouTube channel. By using the App in connection with YouTube, the Operator agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The only Google/YouTube data the App stores is an OAuth authorization token, kept locally on the Operator's personal computer, used solely to upload videos to the Operator's own channel. The App does not access, collect, or store any other YouTube user data, and stores no data on any server.

6. Data Deletion

All locally stored tokens and data can be deleted at any time by the Operator by deleting the App's local data files. Authorization granted to the App can be revoked at any time through the connected platform's account settings: for Google/YouTube, via Google security settings; for TikTok, via TikTok's "Manage app permissions" settings.

7. Contact

Questions about this policy can be directed to the Operator via the contact information associated with the App's developer account.
